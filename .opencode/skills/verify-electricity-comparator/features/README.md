# Feature map

Use this index when choosing an exploratory charter. Each feature should be
driven from the user's point of view, not through internal setters.

| Feature | User path | Proof |
| --- | --- | --- |
| Usage input | Tabs above the chart | Annual value changes the recommendation; custom hourly values change the chart; valid CSV loads and invalid CSV shows an alert |
| Plan ranking | Plans ranked by annual cost | 17 plans, best value, provider/type filters, expandable breakdown |
| Current plan | "Your current plan" select | Savings message appears and names both plans |
| Peak windows | Peak windows card | Editing peak/shoulder hours changes time-of-use costs |
| First-year estimate | Plan cost breakdown | Credits, percentage discounts, and free-power hours change the first-year estimate |
| Error handling | CSV upload | Invalid file produces an accessible alert |

Prefer one charter per exploration step. Verify the outcome on screen with a
role, label, or visible text. Capture a screenshot when the finding is visual.
